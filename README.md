
# ☕ Prácticas y Fundamentos de Java (DAW)

Repositorio de ejercicios, prácticas y proyectos modulares en Java desarrollados durante el ciclo de **Desarrollo de Aplicaciones Web (DAW)**. Abarca desde la sintaxis básica y estructuras de control hasta Programación Orientada a Objetos (POO), manejo de colecciones y persistencia básica.

---

## 📁 Estructura del Repositorio

| Bloque | Descripción |
| :--- | :--- |
| **`scanner/`** | Entrada/salida estándar y ejercicios prácticos (ej. conversor de divisas). |
| **`operadoresasignacion/`** | Uso de operadores aritméticos, lógicos y de asignación. |
| **`condicionales/`, `condicionales2/`, `condicionales3/`** | Estructuras `if / else if / else` y lógica de control. |
| **`switch1/`** | Control de flujo mediante sentencias `switch`. |
| **`bucles/`, `bucles2/`** | Bucles `for`, `while` y `do-while`. |
| **`math/`, `math2/`, `math3/`** | Operaciones numéricas y uso de la clase `java.lang.Math`. |
| **`string/`, `string2/`, `string3/`** | Manipulación de cadenas de texto y métodos de la clase `String`. |
| **`array/`, `array2/`, `array3/`, `array4/`, `arrayBi/`** | Vectores unidimensionales y matrices bidimensionales. |
| **`vector_aleatorio/`** | Generación y tratamiento de arrays con datos aleatorios. |
| **`arraylist/`, `arraylist2/`, `arraylist3/`** | Colecciones dinámicas con la clase `ArrayList`. |
| **`poo/`** | Programación Orientada a Objetos (clases, encapsulamiento, métodos). |
| ↳ `poo/abstractas/` | Clases abstractas y polimorfismo (`factura`, `plantas`). |
| ↳ `poo/herencias/` / `herencias/` | Jerarquías de herencia (`Empleado`, `Vehiculo`, `Persona`). |
| ↳ Proyectos POO | Mini-aplicaciones: `calculadora`, `cine`, `colegio`, `actores_famosos`. |
| **`exception/`** | Control y gestión de excepciones (`try-catch-finally`). |
| **`files/`** | Lectura y escritura básica de archivos de texto (`.txt`). |

---

## 🛠️ Requisitos e Instalación

* **JDK:** Java Development Kit 17 o superior.
* **IDE recomendado:** IntelliJ IDEA, Eclipse o Visual Studio Code (con Extension Pack for Java).

### Clonar el proyecto
```bash
git clone [https://github.com/tu-usuario/nombre-del-repo.git](https://github.com/tu-usuario/nombre-del-repo.git)
cd nombre-del-repo

```

### Compilación y ejecución manual

Para compilar y ejecutar cualquier clase desde terminal:

```bash
# Ejemplo de compilación
javac poo/cine/UsoSalaCine.java

# Ejemplo de ejecución
java poo.cine.UsoSalaCine
